Meta Ads Manager Connection Checklist

To display Ad Spend, Reach, Impressions, Frequency, CPM, and CPC inside this dashboard:

  1. Register a Meta App at developers.facebook.com with Marketing API access.
  2. Generate a System User Token with ads_read permission.
  3. Set META_AD_ACCOUNT_ID=act_<your_id> and META_ACCESS_TOKEN=<token> in .env.
  4. Live spend and campaign ROI will automatically render in this panel.
